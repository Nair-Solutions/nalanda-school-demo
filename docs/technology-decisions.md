# Technology decisions

| Need             | Choice                                                                                                               | Why                                                                                                                                     | Alternatives considered                                                                                                                                                                                              |
| ---------------- | -------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Framework        | **Next.js 16 (App Router) + React 19**                                                                               | Static generation with per-page metadata and hreflang for both languages, a built-in API route for the form, first-class Vercel hosting | Vite + React SPA (the owner's usual stack): weaker SEO and per-route metadata for a content site, and the form would still need a separate serverless function. Astro: good fit, but less familiar to the maintainer |
| Language         | **TypeScript (strict, `noUncheckedIndexedAccess`)**                                                                  | The Hindi dictionary is type-checked against English, so a missing translation fails the build                                          | JS: no compile-time translation checks                                                                                                                                                                               |
| Styling          | **Tailwind CSS 4** with brand tokens in `globals.css`                                                                | Fast, consistent, no runtime cost                                                                                                       | CSS Modules: fine, but slower to iterate                                                                                                                                                                             |
| i18n             | **Typed dictionaries + `[locale]` segment** (the pattern in the Next.js docs)                                        | Zero dependencies; compile-time key parity; tests catch untranslated strings                                                            | next-intl: ICU plurals/formatting aren't needed here ([ADR 0002](adr/0002-i18n.md))                                                                                                                                  |
| Fonts            | **Mukta** (body, Latin + Devanagari), **Noto Serif / Noto Serif Devanagari** (headings), self-hosted via `next/font` | Correct Hindi rendering; no third-party font requests at runtime (CSP `font-src 'self'`)                                                | System fonts only: inconsistent Devanagari across Android/Windows                                                                                                                                                    |
| Icons            | **lucide-react**                                                                                                     | Tree-shaken SVG icons                                                                                                                   | —                                                                                                                                                                                                                    |
| Validation       | **Zod 4** (shared client/server)                                                                                     | One schema, translated error codes                                                                                                      | Hand-written checks                                                                                                                                                                                                  |
| Enquiry delivery | **Resend email** or **generic JSON webhook** (e.g. Google Apps Script → Sheet), selected by env vars                 | No database to run; Sheets suits the owner's existing workflow                                                                          | Formspree/third-party form SaaS: data leaves via another processor and needs a CSP exception ([ADR 0003](adr/0003-enquiry-delivery.md))                                                                              |
| Content editing  | **Typed files in the repo** (`src/content`)                                                                          | Free, versioned and reviewable; content changes rarely                                                                                  | Headless CMS (Sanity, Contentful, Decap): recurring cost or setup for a few edits a year. Revisit if staff need to self-edit ([ADR 0005](adr/0005-content-management.md))                                            |
| 3D / animation   | **None** (CSS transitions only, `prefers-reduced-motion` honoured)                                                   | No user benefit that justifies the bundle and maintenance cost                                                                          | Three.js: rejected                                                                                                                                                                                                   |
| Testing          | **Vitest** (unit), **Playwright** (e2e on 3 viewports), **axe-core** (WCAG 2.2 AA), Lighthouse (manual)              | Real browser coverage of every route and interaction                                                                                    | Jest: slower, no benefit                                                                                                                                                                                             |
| CI               | **GitHub Actions** (lint, format, types, unit, build, e2e, link check)                                               | Free for this repo size                                                                                                                 | —                                                                                                                                                                                                                    |
| Hosting          | **Vercel** (Git integration)                                                                                         | Preview per push, zero-config Next.js                                                                                                   | Netlify, Cloudflare Pages                                                                                                                                                                                            |
