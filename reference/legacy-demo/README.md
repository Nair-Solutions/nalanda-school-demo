# Nalanda Kurud Premium Website Demo

A responsive single-page concept for Nalanda English Medium Higher Secondary School, Kurud.

## Language experience
- A language selection screen appears immediately on page load.
- Visitors can choose English or Hindi before entering the site.
- Main page copy, navigation, form labels/options, accessibility labels, image alt text, page title and meta description are translated for Hindi mode.
- Visitors can switch language using the navigation control at any time.

## Open
Open `index.html` in a modern browser. An internet connection is needed for Tailwind CDN, Google Fonts and illustrative Unsplash images.

## Before production
- Replace illustrative stock images with school-approved campus and student photographs, with appropriate permissions.
- Verify all school-specific facts, class information, address, contact details and public-disclosure documents with school management.
- Connect the enquiry form to an approved secure form handler and publish a privacy notice. The current form is demonstration-only and does not send or store submissions.
- For production, consider bundling Tailwind locally and hosting fonts/images locally or through approved providers.

This is a design demo, not an official school website or a verified source of school information.
